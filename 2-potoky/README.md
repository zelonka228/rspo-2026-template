# 2-potoky — потокова версія (практична 03)

Та сама множина Мандельброта, що в [1-poslidovno](../1-poslidovno), але рядки
роздаються через `ThreadPoolExecutor`. Поруч — друга задача тієї самої форми,
у якій завдання не рахує, а **чекає**. Дві криві на одному графіку й показують
різницю між тим, що GIL блокує, і тим, що ні.

| Файл | Що це |
|---|---|
| `potoky.py` | Мандельброт через пул потоків: еталон + 2/4/8/`cpu_count()`, три прогони, `assert rezultat == base` |
| `ochikuvannya.py` | та сама схема, завдання — 32 × `time.sleep(0.5)` |
| `grafik.py` | обидва заміри на одному графіку |
| `numpy_potoky.py` | ⭐ те саме на NumPy: перевірка, що без GIL потоки працюють |
| `vysnovky.md` | **головне**: чому криві різні |
| `grafik.png`, `grafik-numpy.png` | графіки |
| `vyvid-*.txt` | сирий вивід замірів, з якого взято всі числа |
| `zamiry-*.json` | ті самі числа для `grafik.py` |
| `mandelbrot.pgm` | результат (у git не потрапляє через `.gitignore`) |

```
python potoky.py          # ≈ 3 хв
python ochikuvannya.py    # ≈ 1.5 хв
python grafik.py          # grafik.png

python numpy_potoky.py             # ⭐ ≈ 2.5 хв, з перевіркою проти чистого Python
python grafik.py --numpy           # ⭐ grafik-numpy.png
python numpy_potoky.py --maskamy   # ⭐ два ядра поруч: з масками й без
python numpy_potoky.py --smuhy     # ⭐ розгортка за розміром смуги
```

Для швидкої перевірки: `python potoky.py --shyryna 150 --vysota 100`.

у [vysnovky.md](vysnovky.md), зведена таблиця курсу — у [../zamiry.md](../zamiry.md).

## Дві деталі, які варто знати перед захистом

- **Еталон рахується в тому самому сеансі.** Обидва скрипти спершу проганяють
  послідовну версію й порівнюють уже з нею: у практичній 02 з'ясувалося, що
  розкид між сеансами (8–13 с на тій самій задачі) більший за розкид усередині
  сеансу. Через це число «послідовно» тут — 11.199 c, а не 11.421 c із `zamiry.md`.
- **`pool.map` зберігає порядок.** Рядки повертаються в порядку аргументів,
  а не в порядку завершення, тому результат побітово порівнюваний з еталоном —
  на цьому й тримається `assert rezultat == base`.
