# 1-poslidovno — послідовна версія (практична 02)

Множина Мандельброта на чистому Python, без бібліотек. Це еталон:
і за часом, і за результатом (`base`) для всіх наступних версій.

| Файл | Що це |
|---|---|
| `mandelbrot.py` | реалізація + три прогони з `time.perf_counter`, окремо обчислення й запис |
| `profil.py` | один прогін під `cProfile`, звіт у `profil.txt` |
| `vyvid.txt` | вивід `mandelbrot.py`, з якого взято числа в `zamiry.md` |
| `profil.txt` | профіль, гаряча функція — `iteratsii()` |
| `mandelbrot.pgm` | результат (створюється під час запуску, у git не потрапляє через `.gitignore`) |

```
python mandelbrot.py      # ≈ 35–40 c: три прогони по 11–13 c
python profil.py          # ≈ 30 c, під профайлером повільніше
```

Розмір: 600×400, `max_iter=500`, ділянка [-2, 1] × [-1, 1].
Для швидкої перевірки: `python mandelbrot.py --shyryna 150 --vysota 100`.

Функція `obchyslyty_riadok(y, ...)` рахує один рядок і нічого не знає про
інші рядки — у потоковій і процесній версіях роздається саме вона.

Числа й пояснення — у [../zamiry.md](../zamiry.md).
