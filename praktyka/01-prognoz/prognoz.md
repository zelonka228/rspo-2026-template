## 2.Обрана задача

Множина Мандельброта

Для кожного пікселя зображення окремо виконується обчислення кількості ітерацій. Обчислення різних пікселів не залежать одне від одного, тому основну частину задачі можна розпаралелити між ядрами процесора.

### 3 Послідовна частка

Оціночна послідовна частка: s ≈ 0.01 (1%).

Основна частина обчислень для множини Мандельброта добре розпаралелюється, оскільки кожна точка зображення обробляється незалежно від інших

#### 4 Закон Амдала

Формула закону Амдала:

> > > S(N) = 1 / (s + (1 - s) / N) \
> > > де: s = 0.01 — послідовна частка;\
> > > N — кількість ядер;\
> > > S(N) — теоретичне прискорення.
> > >
> > > ### Для 16 логічних ядер
> > >
> > > S(16) = 1 / (0.01 + 0.99 / 16)
> > > S(16) ≈ 13.91 \
> > >
> > > ### Для нескінченної кількості ядер
> > >
> > > S(∞) = 1 / s
> > > S(∞) = 1 / 0.01 = 100

## 5. Прогноз

На моєму процесорі доступно 16 логічних ядер.

Теоретичне прискорення за законом Амдала для 16 ядер становить
**13.91×**.

З урахуванням накладних витрат на створення потоків, розподіл роботи
та синхронізацію очікую фактичне прискорення приблизно **10–13 разів**.
